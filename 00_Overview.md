# NoDAW Studio: Overview

NoDAW Studio is a CLI-first toolkit that wraps FFmpeg, SoX, Rubberband, Pedalboard, and Demucs into one workflow. The goal is fast, repeatable, high quality processing without a DAW.

**Core Modules**
- FFmpeg: format conversion, filters, mastering chains, video utilities
- SoX: high quality resampling, dehum, de-essing, trims
- Rubberband: time stretch and pitch shift
- Pedalboard (Python): EQ, compression, reverb, stereo tools, loudness
- Demucs: stem separation

**Philosophy**
- One to three knobs per effect when mapped to GUIs
- Deterministic presets in CLI for repeatability
- Clear file naming and logs
